# UI Contract: 阅读页（GitBook / Stripe 风格）

**目标**：侧重**阅读体验**；桌面端 **三栏**，顶栏 **全站搜索** 与 **主题切换**。

## 路由

- 壳：`{BASE_PATH}/docs` 与 `{BASE_PATH}/docs/*`（具体 slug 规则与 `data-model.md` 一致）。  
- **静态路由优先**：`/docs`、`/docs/search`（若独立结果页）须在通配前注册。

## 布局（桌面 ≥ `lg`）

| 区域 | 行为 |
|------|------|
| **顶栏** | 品牌/返回主站链接（可选）、**全局搜索框**（回车或按钮触发检索）、**深色/浅色切换**、窄屏 **汉堡菜单**（打开左栏抽屉） |
| **左栏** | **导航树**：按 **快速入门、设备接入、技能开发、API 参考** 四大分区**分组标题** + 各分区下树；当前 slug **高亮**；可滚动 |
| **中栏** | **Markdown 渲染**：最大阅读宽度、舒适行高；代码块带语法高亮 + **「复制代码」**；表格可横向滚动 |
| **右栏** | **当前页 TOC**：由标题生成锚点列表，点击平滑滚动至对应 `id` |

## 布局（移动 / 平板）

- 左栏：**抽屉**；右栏 TOC：折叠为正文上方 **「本页目录」** 可展开块或底部抽屉。  
- 顶栏搜索保持可用。

## 视觉

- **非衬线字体**（系统栈或计划中的 Inter / Noto Sans SC）。  
- **深色 / 浅色**：`localStorage` 记忆；首访可跟系统 `prefers-color-scheme`。  
- 代码块：与主题配套的 **dark/light** 高亮主题（Shiki/hljs 主题对）。

## 无障碍

- 搜索框、`aria-label`；跳过链接至主内容；锚点标题层级与单一 `h1` 策略在实现时统一。

## 非目标

- 阅读页不提供用户评论；不提供 WYSIWYG（见 spec FR-010）。
