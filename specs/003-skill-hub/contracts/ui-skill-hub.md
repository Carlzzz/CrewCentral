# UI Contract: Skill 技能下发中心（003-skill-hub）

**Date**: 2026-04-07  
**Route**: `{BASE_PATH}/admin/skills`

## 页面结构

1. **左侧分类导航（固定宽度）**  
   - 全部  
   - 自动化  
   - 采集  
   - 社交  
   - 自定义  
   - 显示每类数量（可选）

2. **右侧技能卡片网格（主区域）**  
   - 响应式列数：大屏 4 列，中屏 2-3 列，小屏 1 列  
   - 支持搜索关键字与分页/懒加载

3. **顶栏操作**  
   - 上传技能包按钮  
   - 分类/关键字筛选  
   - 跳转权限配置页入口

## 技能卡片元素

| 元素 | 内容 | 交互 |
|------|------|------|
| Icon | 技能图标 | 默认占位图兜底 |
| 标题区 | 技能名称 + `vX.Y.Z` | 点击进入技能详情 |
| 描述 | 1-2 行简短描述 | 超长省略 |
| 分发开关 | 全设备/分组分发 | 一键启停，失败回滚 UI 状态 |
| 配置按钮 | “配置” | 跳转参数配置页 |
| 悬浮快捷入口 | “查看文档”“部署” | hover 时显示，键盘可聚焦 |

## 视觉与交互细节

- 卡片默认阴影轻；悬浮时阴影加深并提升层级。  
- 操作按钮显示加载态，防重复提交。  
- 分类切换与搜索触发同一列表查询管线。  
- `prefers-reduced-motion: reduce` 时弱化动画。

## 权限配置页（`{BASE_PATH}/admin/skills/assignments`）

1. **左右双栏布局**  
   - 左栏：用户/用户组选择（搜索 + 树形或列表）  
   - 右栏：技能勾选列表 + 配置编辑区

2. **配置编辑能力**  
   - 支持 JSON 编辑器（语法高亮、基础校验）  
   - 可选可视化表单（按技能 schema 渲染）  
   - 保存前必须通过结构校验并提示错误定位

3. **结果反馈**  
   - 保存成功提示并刷新绑定状态  
   - 保存失败保留草稿并显示差异提示
